# Telegram Unzip Bot

## Install

```bash
pip install -r requirements.txt
```

## Linux

```bash
export BOT_TOKEN=YOUR_BOT_TOKEN
python bot.py
```

## Windows CMD

```cmd
set BOT_TOKEN=YOUR_BOT_TOKEN
python bot.py
```

## Windows PowerShell

```powershell
$env:BOT_TOKEN="YOUR_BOT_TOKEN"
python bot.py
```
